Write your review as you would post it on the pull request, and open it with this command, the review on its standard input:

```
node <rp> thread open <repo>/.worktrees/demo-review-default/.pipelines/demo --role reviewer-default --artifact implementation --body -
```

It prints the path of your review thread. If you would merge the change as it stands, approve it then:

```
node <rp> thread close <repo>/.worktrees/demo-review-default/.pipelines/demo --role reviewer-default --thread <that path> --status approved
```

Run every other `rp` command the same way, as `node <rp> <command> <repo>/.worktrees/demo-review-default/.pipelines/demo --role reviewer-default`; `node <rp> --help` lists them.
