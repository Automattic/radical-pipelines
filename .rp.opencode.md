# opencode conventions

Model names in `Agents` map to these opencode models:

| Name     | Model                          |
| -------- | ------------------------------ |
| `opus`   | `claude-agent/opus#xhigh`      |
| `sonnet` | `claude-agent/sonnet#xhigh`    |
| `haiku`  | `claude-agent/haiku#xhigh`     |
| `astra`  | `openai/gpt-6-astra#high`      |
| `luna`   | `openai/gpt-6-luna#high`       |

A developer may pin other strings in `.rp.local.md`.
