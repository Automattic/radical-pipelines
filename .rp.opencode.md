# opencode conventions

The orchestrator spawns a role whose `Agents` model is one of these names on its opencode model:

| Name     | Model                          |
| -------- | ------------------------------ |
| `opus`   | `claude-agent/opus#xhigh`      |
| `sonnet` | `claude-agent/sonnet#xhigh`    |
| `haiku`  | `claude-agent/haiku#xhigh`     |
| `astra`  | `openai/gpt-6-astra#high`      |
| `luna`   | `openai/gpt-6-luna#high`       |

A developer may pin other strings in `.rp.local.md`. A role finds its subagent model by its name through opencode's model search instead, so its subagents run on the model that search finds, without the variants above.
