BREAKING: Architecture v3. A pipeline is a converging set of artifacts: state is computed from the working tree (body-hash identities, pins in frontmatter written only by the orchestrator's `rp stamp`, `rp check` reporting the frontier), corrections are amendments that cascade through staleness instead of forks and revisions, and every artifact loop carries a third verdict — `unsatisfiable` — that routes a contradiction to the artifact that must change, up to the owner when it contradicts a recorded owner statement. Spec and design phases verify by inspection only and label what they cannot verify as assumptions that build verifies first. Profiles are rewritten on one schema (Role, Seat, Modes, Rules, Protocol, Formats) with prompt templates in the skill; consolidators become a producer mode; writers become workers; research goes through one `researcher`. Tool mechanics move from `.rp.md` into the skill's `tools/` files; `.rp.md` gains a `conventions` schema stamp with a migration changelog. Blockers only report malformed materials or a broken environment.  The opencode plugin now removes retired profiles when it materializes agents.
