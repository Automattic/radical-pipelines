BREAKING: the near-identical `spec-researcher` and `design-doc-researcher` profiles merge into a single `researcher` serving the spec, design-doc, and amend phases — model configuration and spawns keyed to the old names must migrate. Add the amend pattern: a reduced pipeline for small, fully pinned changes. An amend runs a single `1-amend` phase — an `amend-lead` researches the change through per-question researchers and writes `amend-plan.md` (spec and design substance plus the task list in one artifact), an `amend-plan-reviewer` adjudicates it, writers execute the tasks (documentation included, via a new `doc` task type routed to the document writer), and an `amend-reviewer` reviews the whole diff and runs the gates. Amends layer on a complete run (sharing the revision counter: `rev-1`, `amend-2`, …) or serve as a pipeline's base run; the orchestrator recommends one only when the change qualifies — pinned target, no open design decisions, a touch map that closes — and any agent that surfaces a disqualifying discovery ejects the run toward a revision or full pipeline. Both workflow modes apply, with assisted covering the plan half.
