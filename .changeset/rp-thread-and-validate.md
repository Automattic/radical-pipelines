Roles write their threads and check their own files through `rp`, so a role fixes a malformed file in the turn that wrote it instead of being woken again to repair it.

`rp thread open`, `rp thread reply`, `rp thread close`, and `rp thread escalate` write a thread's file name and number, `<n>-<opener>-<recipient>-<about>.md`, its header, and each message heading, naming the commit the role's worktree stands on, around the body the role gives with `--body <file | ->`, written as given. Each writes only a file `rp check` accepts and reads as meant. A wrong use writes nothing and says what was wrong and what to run instead: a production lane opening a thread, a thread about the intent instead of an escalation, a reply to a thread that does not await the role, a close by a role other than the opener, a review approved without a closing message after the author's answer, an empty body, or a body line the grammar would read as a heading or fenced code left open. `rp thread open` takes what the thread is `--about`, and `rp thread close` closes a review thread `approved`, any other `resolved`, or either `withdrawn`. `rp validate` prints, for each of the role's own files, the `malformed` line `rp check` prints for it, or that they are accepted, and stops where `rp check` stops on a path of the wrong kind that holds them. All five apply the file grammar alone, never the pipeline configuration, so they work in a review lane's tree too.

Every assignment states the command that runs `rp` as its role, each path on it one shell word, so it runs as written whatever characters its paths hold. The reviewer's templates open, answer, and approve through `rp thread`, passing each message through a quoted heredoc, and the first-turn template names no thread path. The agent profiles name the commands instead of the thread grammar, and each role runs `rp validate` and fixes each file it reports before it ends a turn. A command line any `rp` command does not take, such as an unknown option or a missing argument, is now followed by the command's form.
