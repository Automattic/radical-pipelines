Give every dispatched agent a Supporting folder in its Seat — named after what it writes, without `.md`, beside it; a helper's is its requester's plus `helper-<n>/`. The agent keeps there, redacted and committed with its file, the screenshots, logs, command output, transcripts, and helper answers that file cites. The helper prompt drops `## Write findings to`: a findings file goes in the helper's Supporting folder.
